## ☀️ PROJECT SUMMER — Active Build

> *A next-generation, Jarvis-class AI operating system with autonomous agents, ego-aware memory, deep desktop integration, and self-evolving capabilities. Not a chatbot — a cognitive layer for your machine.*

### What makes Summer different

| Layer | Capability |
|---|---|
| 🧠 **Memory** | Ego-aware knowledge graph · semantic vector search (pgvector) · session diary · importance-scored "pinned" facts · temporal timeline visualization |
| 🤖 **Agents** | Code · Research · Business · Creative · Personal — each with sub-specialists; Fact Checker, News Monitor, Trend Analyzer as Tier 2 plugins |
| 🔄 **Cortex** | Autonomous self-evolution engine — detects gaps → forges skills → AST-validates in sandbox → promotes via staging → opens Git PRs |
| 🖥️ **OS Control** | Volume, brightness, DND, diagnostics, Spotify, WhatsApp, Finder, clipboard, screenshots — full machine control |
| 📺 **HUD Overlay** | Unified full-screen transparent canvas · 3-zone tiling layout engine · pointer watchdog · click-through |
| 🌐 **Browser** | Autonomous Playwright mini-browser · human-in-the-loop · multi-tab · Drive PDF live Q&A |
| ☁️ **Cloud** | Multi-Google-account OAuth · Supabase sync · Drive media streaming |

**Stack:** `Electron 41.5` · `Google Gemini 3.1 Flash` · `Node.js` · `Swift/SwiftUI` · `Python` · `pgvector` · `Supabase` · `Playwright` · `WebSockets`
